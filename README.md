# Py-Section 1 Mission Project: The Digital Translator

**Author:** Paul Fabian

This project explores one central idea: a computer cannot understand the real world directly. A human has to translate a real-world problem into precise **data** and **instructions** that the computer can process.

## Key takeaways
- **Tier 1:** Humans fill in missing information. Computers cannot, so every detail must be explicit.
- **Tier 2:** A problem is a goal. An algorithm is the step-by-step solution, including how to handle failure.
- **Tier 3:** Every program follows INPUT -> PROCESS -> OUTPUT, and good programs validate input first.
- **Tier 4:** Data is information represented in a form a computer can store, process, and communicate.
- **Tier 5:** Customer input, program, instructions, processing, stored data, and output work together as one system.
