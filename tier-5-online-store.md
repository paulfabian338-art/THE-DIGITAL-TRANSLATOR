# Tier 5 - Architecture Challenge: The Online Store

## Scenario
A customer orders a product from an online store.

## The chain
```
Customer
   |
Input (data entered)
   |
Application / Program
   |
Instructions
   |
Data Processing
   |
Stored Data
   |
Result / Output
```

## Explaining each stage

### 1. Customer input
The customer gives the system data:
- The product they want
- The quantity
- Delivery information
- Payment information

### 2. Application / Program
The online store application receives that data. It holds the instructions that tell the computer what to do with it.

### 3. Instructions
The program tells the computer to:
- Identify the selected product
- Check that it is in stock
- Calculate the order total
- Process the payment and order details
- Update the records

### 4. Data processing
The computer carries out the instructions on the data.
```
Product price: 50,000
Quantity:      2
--------------------
Order total:   100,000
```
Input data goes in, and new information (the total) comes out.

### 5. Stored data
The system saves what it needs to remember:
- Customer
- Product
- Quantity
- Order amount
- Order status (for example: paid, packed, shipped)

All of this is stored as digital data.

### 6. Result / output
The system responds to the customer:
```
Order confirmed. Total: 100,000.
```

## Final challenge: the chain in my own words
```
Customer
   |
Enters order data (product, quantity, delivery, payment)
   |
Program receives the data
   |
Program runs its instructions (check stock, calculate total, save order)
   |
Computer processes and stores the data
   |
Result (order confirmation)
```

## Answering the questions

**What is the computer doing?**
The computer is the machine that carries out the work. It executes the program's instructions step by step: reading the input, doing the calculation, saving the order, and sending back the confirmation.

**What is the program doing?**
The program is the set of instructions. It decides what should happen: check availability, calculate the total, record the order, and produce the message.

**What data is involved?**
Product name, price, quantity, delivery address, payment details, the calculated total, and the order status.

**What instructions are being executed?**
Identify the product, check stock, multiply price by quantity, process payment, save the order, and display the confirmation.

**What is the output?**
The confirmation message, for example "Order confirmed. Total: 100,000."

**What information might need to be stored for the system to remember the order?**
Customer, product, quantity, order amount, delivery details, payment status, and order status. Without storage, the system would forget the order as soon as the page closed.

## How the concepts relate
The customer's **data** goes into a **program**. The program contains **instructions**. The computer follows those instructions to **process** the data. Results that must be remembered become **stored data**, and the customer sees the **output**. Each concept depends on the one before it.
